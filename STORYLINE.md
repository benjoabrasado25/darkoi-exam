# Publishing in Storyline 360 → Review 360 link

The trial task asks for a **Review 360 link**. These steps take the game folder to that link.

## 1. Set up the slide
1. Open Storyline 360 and create a new project.
2. **Design → Slide Size → 720 × 540 (4:3).**
3. Choose **Blank** for the slide layout.

## 2. Insert the game as a Web Object
1. **Insert → Web Object.**
2. In **Address**, click the folder icon and choose this whole folder (the one containing `index.html`). Storyline copies the folder into the project.
3. **Display:** *In slide*. **Show:** *Automatically*.
4. Click **OK**, then set the Web Object's **size to 720 × 540** at **X 0, Y 0** (Size and Position, Ctrl+Shift+Enter).

> Web Objects don't run in Storyline's Preview. Publish to see the game working.

## 3. Optional player tidy-up
- **Home → Player:** turn off the menu, resources, seekbar and title so only the game shows.
- **Slide properties:** set *Slide advances* to **By user**, so the slide doesn't move on while the child plays.

## 4. Publish to Review 360
1. **Home → Publish → Review 360.**
2. Give it a title, for example "Set the Clock – Trial Task", and click **Publish**.
3. When it finishes, click **Copy link** (or **View project**, then **Share**) and send that link.

## 5. Check the published link
- Open the link in Chrome and on a phone or tablet.
- Tap **Start**, listen to the prompt, drag both hands, try a wrong answer, then finish all 10 questions.

If no sound plays, make sure the device isn't muted. Browsers only allow sound after a tap, which is why the game starts with the Start button.
